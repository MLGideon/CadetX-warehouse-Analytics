# CadetX-warehouse-Analytics

# Project overview 
CadetX warehouse analytics is a data analytics project developed as part of the Virtual internship experience program. The project focuses on analysing Heavy Supplier, Inventory, Warehouse and other datasets to understand and optimise supply-chain operations, inventory health and warehouse efficiency though structured analysis with the aim of solving complex challenges and helps in making a better and informed business decisions. 

The project follows a structured analysis workflow:

Data Loading - Data Cleaning - Data standardization - Data validation - Feature Engineering - KPI Development - Performance Dashboard analysis.
